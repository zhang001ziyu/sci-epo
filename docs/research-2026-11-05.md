# Sci-epo 同类产品与技术调研

> 当前第一阶段已按作者要求调整为[剧本优先](script-first-plan.zh-CN.md)。本文的视频工具选型和动画实验留待剧本验收后，不再作为首项开发工作。

调研日期：2026-11-05。优先采用作者帖文、官方产品页、GitHub 当前 README、许可证与部分源码。功能说明不等于独立性能测评；本次未安装并端到端运行所有项目，也未付费调用生成模型。

## 选用顺序

1. **lemo-opuscar / scifi-toon** 最贴近参考片，优先验证二维角色、对白时间轴与渲染方法。
2. **Toonflow、Moyin Creator、LTX Studio** 参考完整创作交互：资产、分镜、采用版本和局部修改。
3. **HyperFrames** 作为渲染服务候选；**Remotion、Motion Canvas** 比较其他工程路线，首版不同时集成。
4. **LTX Desktop** 留作生成式镜头实验；**waoowaoo** 当前许可和预览功能有变化，不照旧介绍直接采用。

选型按功能与源码结构匹配，不用星标数量代替质量、性能或商业可用性。

## 原视频与核查范围

[lemomo_ai 原帖](https://x.com/lemomo_ai/status/2117809549331886091) 将其描述为成人科幻情景喜剧，提出固定角色和持续写故事的方向。

浏览器读取原帖媒体，实测 57.557333 秒；抽查 4、17、24、33、42、47、51 秒画面，与仓库 `Coffee Run` 剧本和时间轴核对。未进行完整音轨听审或逐帧测评。

观察到两位固定主角、粗深色轮廓、平涂、夸张眼睛/嘴形、不同世界色板及说话人字幕。故事由咖啡机故障引出异常世界，回到实验室后用人物执念回扣。动作步频和嘴形驱动方式来自源码，不能只由截图推断。Sci-epo 借鉴机制，角色、故事和场景另行原创。

## lemo-opuscar 的实现参考

实时风格索引为 66 种，本地旧技能描述为 59 种，以实时仓库为准。

- [`story.js`](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/scifi-toon/demo/story.js)：镜头区间、对白起点、动作事件与音乐 cue；片长 57.5 秒，角色步频 12 fps。
- [`voice.py`](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/scifi-toon/demo/voice.py)：用 RMS 和频谱重心生成嘴部开合/形状数据，是简化声音驱动，不是音素级精准嘴形。
- [`chars.js`](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/scifi-toon/demo/chars.js)、[`worlds.js`](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/scifi-toon/demo/worlds.js)：目录和风格文档表明角色与世界绘制分别组织，本次没有完整审计两文件。
- [`core/README.md`](https://github.com/lemomo-ai/lemo-opuscar/blob/main/core/README.md)：`READY`、`render(t)`、`DUR` 页面约定，另有字幕、阅读时长、声音与混音工具。
- [`video.mjs`](https://github.com/lemomo-ai/lemo-opuscar/blob/main/core/render/video.mjs)：逐帧调用 `render(t)`，浏览器截图送 FFmpeg，再合并分段。有输出锁和分段并行，不能等同持久项目队列或逐镜增量构建。

Sci-epo 需增加结构化工程、资产版本、镜头依赖、可编辑预演、持久任务和系列连续性。具体复用文件在样片实验后决定；本次没有复制第三方实现进项目。

当前 [Licence 说明](https://github.com/lemomo-ai/lemo-opuscar#licence) 区分：代码/文档 MIT；示范影片及静帧 CC BY 4.0，另列三个语音轨道例外。不能将所有素材统一视为 MIT。复用时保留来源和适用条款，原创样片采用新角色、新故事和有使用权的声音。

**waoowaoo**：旧目录仍可能写 CC BY-NC-SA 或完整小说到影片。当前 [README](https://github.com/waooAI/waoowaoo/blob/main/README.md) 明确预览范围；v0.5.0-beta.1 起改为 [Elastic License 2.0](https://github.com/waooAI/waoowaoo/blob/main/LICENSE)，限制向第三方提供覆盖实质功能的托管/管理服务。旧版保留各自许可，不能混用结论。

## 首次技术实验

用同一个 15 秒原创双人对白片段：中景对话、反应近景、一个拿取道具动作。固定角色、台词与输出规格，先运行程序动画。

| 记录项 | 比较目的 |
| --- | --- |
| 制作耗时、渲染耗时、人工修复时间 | 分开衡量创作和算力负担 |
| 跨镜头身份、声音、持物状态 | 验证同一个人物在演同一场戏 |
| 对白动作同步、停顿和反应 | 检验喜剧表演 |
| 修改一句台词后的重做范围 | 检验依赖与缓存价值 |
| 含失败尝试的成本 | 避免拿宣传案例单价当预算 |
| 重开工程和任务中断恢复 | 检验可持续生产 |

如果程序路线在画面或动作上达不到目标，再用同一素材试一个生成式视频后端；写下比较结果后决定长期依赖。
