# Sci-epo

Sci-epo is a script editor in development for independent animators making short sci-fi cartoons. Give the writer's room one premise and one rule, then ask it for a three-scene episode. When a writer wants a different punchline, the planned editor will let them keep the setup and check the rewritten action against what happened earlier.

## Read the pilot

Pip spends her last jetpack burst saving a birthday cake in a zero-gravity mailroom. A second burst would be an easy way back to the hatch. It would also contradict the shot where the fuel gauge went dark. A loose metal lid in the opening scene gives Pip another way home.

1. Read the [75-second pilot, *One Puff Left*](examples/one-puff-left.md).
2. Inspect the [scene data and the contradictory ending](examples/one-puff-left.json). The first two scenes are locked. The last scene can be rewritten.
3. Compare the proposed endings. Throwing the lid costs no fuel. Firing the pack again spends a charge that scene two already used.

## Kiroween 2026

The proposed category is **Frankenstein**. The design pairs a generative writing model with a game-style resource counter so a writer can see where a proposed joke breaks continuity.

This planning snapshot contains the pilot, test data and [steering prepared for Kiro](.kiro/steering/episode-continuity.md). The generator, checker, hosted application and demo video are upcoming milestones.
